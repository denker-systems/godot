# Godot Engine Workflows

Windsurf workflows för Godot Engine utveckling.

## Tillgängliga Workflows

| Workflow | Slash Command | Beskrivning |
|----------|---------------|-------------|
| build | /build | Bygg Godot Engine |
| init-session | /init-session | Starta utvecklingssession |
| end-session | /end-session | Avsluta session |
| new-module | /new-module | Skapa ny engine module |
| git-commit | /git-commit | Committa ändringar |
| debug | /debug | Debugging workflow |
| run-tests | /run-tests | Kör tester |
| research | /research | Utforska kodbasen |
| update-docs | /update-docs | Uppdatera dokumentation |

## Snabbstart

1. `/init-session` - Starta din session
2. `/new-module` - Skapa en ny module
3. `/build` - Bygg och testa
4. `/git-commit` - Committa ändringar
5. `/end-session` - Avsluta sessionen
